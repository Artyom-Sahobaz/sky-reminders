    Leave empty to use the one built into Sky Reminders.

    Secret iCal addresses optional, no sign-in

    For personal Gmail calendars, no sign-in needed. For each calendar:
    1. Open calendar.google.com signed in with that account.
    2. Settings (gear) → under Settings for my calendars, pick the calendar.
    3. Scroll to Integrate calendar → copy Secret address in iCal format.
    4. Paste it below. One address per line; you can mix accounts.
    The secret address works like a password for that calendar's events, so it is stored only on this PC.
